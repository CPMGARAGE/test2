BUILD A SAVE FILE

Pick what you want unlocked and download a backup file the game can import.

To use it, open the game, choose Save data, then Import backup. Importing replaces the save on that device, so export your current one first if you want to keep it. Everything here runs in this page; nothing is uploaded.

PROGRESS

Levels and missions are cleared in order, so 7 means 1 through 7. Clearing a level also unlocks its tank and shell, and later ones add their maps and home screens.
